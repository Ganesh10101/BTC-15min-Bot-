# Research hypothesis

**H1:** Following a major reversal, the conditional frequency and/or payoff of subsequently filled 1-cent contracts changes as a function of elapsed completed 15-minute market intervals. A 50–80 interval exclusion window may improve fill-adjusted expected returns relative to no exclusion.

**H0:** There is no economically meaningful improvement after accounting for fees, fills, and selection effects.

## Required validation

1. Specify the reversal event using only information available at signal time.
2. Define contract side and entry timing before analyzing outcomes.
3. Compare 0, 50, and 80 completed-market cooldowns.
4. Evaluate out-of-sample results and confidence intervals.
5. Account for non-filled bids and execution fees.

A 1-cent price is not itself evidence of a 1-in-100 chance of winning.
